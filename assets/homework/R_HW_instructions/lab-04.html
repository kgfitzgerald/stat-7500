Data: The Portland Thorns FC

For this assignment, you will be working with data about the Portland Thorns FC, a National Women’s Soccer League (NWSL) Team in Portland, OR. In 2021, the Thorns won the NWSL Challenge Cup, the Women’s International Champions Cup, and the NWSL Shield. Data for this lab was sourced from the nwslR package.

The package comes with built-in functions that allow you to pull data from a Github repo:

  • load_matches(): All matches from 2016-present with information and match IDs
  • load_players(): All players rostered from 2016-present with information and player IDs
  • load_teams(): All teams active from 2016-present with information and team IDs
  • load_metrics() All metrics available from scrapers with definitions. Not all metrics are available for all players/matches/teams/etc.

Running the following code will make four datasets appear in your Environment.

matches <- load_matches()
players <- load_players()
teams <- load_teams()
metrics <- load_metrics()

  1. Inspect the teams data to determine the team_id for the Portland Thorns. Filter the matches dataset to only keep matches where Portland was playing. Save this as a new dataset called portland_matches. Confirm that your new data has 223 observations before proceeding.

We want to add in information from the teams data into the matches data so we can have the team name and abbreviation in addition to just the numeric team id. However, we will have to join the teams information twice: once for home team and once for away team. We want to end up with the following four variables added to the portland_matches data:

  • home_team_name

  • home_team_abbr

  • away_team_name

  • away_team_abbr

The following code creates a new dataset called home_team_info that selects the relevant columns from teams and renames them to include the prefix home_ . It then joins these columns to the portland_matches data.

home_team_info <- teams |> 
  select(home_team_id = team_id, 
         home_team_name = team_name, 
         home_team_abbr = team_abbreviation)

portland_matches <- portland_matches |> 
  left_join(home_team_info)

Player stats

The code below loads data for players’ individual stats for the matches in portland_matches. Don’t worry too much about how this code is working, it is provided by the nwslR package. Note, it takes a few minutes to run!

# * A small number of matches do not have data, so we wrap this in a safe call to ensure this runs without error 
safe_load_pms <- purrr::possibly(load_player_match_stats, otherwise = data.frame())

player_stats <- purrr::map_df(portland_matches$match_id, safe_load_pms, .progress = TRUE)
